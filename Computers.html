The advancment of Computers

Charles Babbage is known as the father of the computer, he designed he Analytical Engine, a mechanical device with basic fatures of a modern computer, including an arithmetic logic unit, control flow, and memory. Babbage laid the groundwork for computing concepts. Grace Hopper invented the first complier, a program that translates human-readable code into machine language, making programming more accesible. she also contributed to the creation of COBOL, one of the first high-level programming languages. Tim Berner-Lee Invented the World Wide Web, which revolutionized how we interact with computers and gae rise to web-based coding languages like HTML, CSS, and JavaScript.
